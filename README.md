


AutoGen Weather Agent

A Python-based weather agent built using the Microsoft AutoGen Framework and DuckDuckGo Search. It searches weather webpages and uses an AI agent to summarize current weather conditions and forecasts.

 Features
- Search weather information using DuckDuckGo.
- Extract webpage content using Requests and BeautifulSoup.
- Summarize results using AutoGen AssistantAgent.
- Display results in a concise, three-point format.
- Accept any city as user input.

 Technologies
- Python
- Microsoft AutoGen
- DuckDuckGo Search (ddgs)
- Requests
- BeautifulSoup
- OpenAI API

Enter a city when prompted, for example Paris.
Note
Weather results depend on the webpages returned by DuckDuckGo. Live conditions may not always be available or verifiable.
